# Kyoo trial

Kyoo runs on Adam at `https://stream.zekurio.me`. Caddy allows LAN and
Tailscale clients only. Add a DNS rewrite on Flint from `stream.zekurio.me`
to `10.0.0.2` before use.

Each component has its own NixOS OCI container and systemd unit. The files
in this directory define the database, auth, API, frontend, scanner,
transcoder, and proxy. `default.nix` sets the image version, shared settings,
Podman network, and `kyoo.target`. No Compose files are used.

The service settings follow the
[Kyoo 5.2.1 release](https://github.com/zoriya/Kyoo/releases/tag/v5.2.1).
Traefik reads routes generated by Nix. It exchanges login tokens before
forwarding API, scanner, and video requests. It has no Podman socket access.
Caddy handles TLS and private access. Only `127.0.0.1:8901` is bound on
Adam. The other ports are reachable within the Kyoo container network.

The scanner and transcoder mount `/tank/media` as read-only. The scanner
skips music and download folders. The transcoder uses VA-API on
`/dev/dri/renderD128` and stores its cache in `/var/cache/kyoo`.

Kyoo uses bind mounts under `/var/lib/kyoo`: `postgres`, `images`,
`metadata`, and `profile-pictures`. These are trial data on the root disk.
The module does not add a backup policy for them. Stopping the services
removes the containers but keeps these directories. Kyoo has no existing
instance to migrate.

Deploy through the commit, push, and rebuild steps in the root `AGENTS.md`.
Then open the site from the LAN or Tailscale and create the first account.
Kyoo gives that account admin rights. Later accounts need admin verification
before playback. Guest access is off.

The encrypted `kyoo_postgres_password` and `kyoo_api_key` secrets supply the
database password and scanner API key. Each container gets only the secrets
it needs. Edit them through SOPS. Changing the database password in SOPS
does not change an existing PostgreSQL role. Rotate that role's password
at the same time.

Use `sudo systemctl restart kyoo.target` to restart all Kyoo services.
Use `systemctl status podman-kyoo-api` or `journalctl -u podman-kyoo-api`
to inspect one service. Replace `api` with `auth`, `front`, `scanner`,
`transcoder`, `postgres`, or `proxy` for another service.

To update Kyoo, change `version` in `default.nix` and check the new release's
service settings. PostgreSQL and Traefik have separate image tags in their
own modules. The database health check delays its clients until PostgreSQL
accepts TCP connections.
